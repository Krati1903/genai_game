# GenAI Dashboard

Welcome to the GenAI Dashboard project! This application serves as a comprehensive dashboard for interacting with AI models and visualizing insights.

## Project Structure

The project is organized into the following directories:

- **app/**: Contains the main application files, including layout, pages, and API routes.
- **components/**: Houses reusable React components such as Navbar, Sidebar, and ChatWindow.
- **lib/**: Contains utility functions and libraries for interacting with AI models and managing data.
- **hooks/**: Includes custom hooks for managing state and logic within the application.
- **types/**: Defines TypeScript types and interfaces used throughout the project.
- **public/**: Contains static assets like robots.txt and site.webmanifest.
- **styles/**: Includes global CSS styles for the application.

## Getting Started

To get started with the GenAI Dashboard, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd genai-dashboard
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Run the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.

## Features

- Interactive dashboard for AI model interactions.
- Real-time chat interface for conversations with AI.
- Insights presentation through cards and visualizations.
- Model selection for different AI functionalities.
